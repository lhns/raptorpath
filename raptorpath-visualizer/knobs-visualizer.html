This is not a toy model. Each tick calls the production rate formula (shared raptorpath-math::controller_rate) with correction preemption, Plost repair/retransmit mixing, the completion ramp (§3.3, §4.6) and the saturation cap; the multipath model carries per-path own-RTT recovery clocks (§7.1) and SACK-clocked store release (§6.3). Its retention pool is a constant 512 slots/path (an underived model constant), not the engine’s pooled cap (§6.1). The estimator learns outcomes one RTT late — watch ε̂ lag the channel after a loss burst. Channel and δ changes apply to the simulation on Reset; the span-machine panel morphs live.

At N ≥ 2: per-path clocks (§7.1), 9/8 time threshold + kPacketThreshold = 3 same-path fast channel; c8 holes were seen only at ≈ 3.5 s age (C02, measured before the snapshot-order law) per-path clock = 1 own-RTT from send at every N, including N = 1 (per-symbol acks make the packet-threshold channel no faster here); no srtt/2 age gate
snapshot order the sender judges reported holes only from the receiver’s newest snapshot (§7.1, A.6) vacuous here: the model has per-symbol acks with instantaneous forward flight and no gap reports, so no report can arrive out of receiver order
L1 intake expiry (T, §2.1) none (proposal; engine has none) a unit with age ≥ T at the intake is never sent; counted in intake_expired; absolute test: l1_viol = 0 over every payload datagram
L2 resend admissibility (T, §2.2, §17.1) none (proposal; engine has none) a resend is sent only if age + ô < T, with ô = srtt − rtprop/2 (the model has no queue, so RTT/2)
L3 delivered-within-T (§2.3) none (proposal; engine has none) a readout, never a branch: share_T, share_by_ref (τ = 0.4 s); exact here because the model has one clock
dequeue expiry (§13.2) none (proposal; engine has none) at the dequeue a unit gives its slot to a younger waiting one when age + R ≥ T (R = ack timeout, RFC 6298); only reachable with a finite-rate source
floor and protected (§15.3, §17.1) none (proposal; engine has none) F_ann a running maximum from the ack frontier; a hole is protected while max(now, last send + d) − h + ô < T; floor repeat on the sweep clock clamp(2·srtt, 25, 100 ms); the cartoon uses its own times (d = RTT)
L6 order hold (H, §2.6) none (proposal; engine has none) a hole is released at min(t_detect + H, t_floor + H_f); consumer stage with bind gauges rel_by_hold / rel_by_floor; no reorder buffer limit is modeled
hand-over h(u) = u/λ (§13.2) none (proposal; engine has none) the source arm sends unit u only once h(u) ≤ now; λ = ∞ hands everything over at t = 0 (the object)
outage window (§13.5, §17.4) none (proposal; engine has none) a per-path window [start, start + length) in which every wire send is lost; the channel state still advances so the post-outage pattern stays aligned; recovery time uses 50-unit hand-over windows (plan §4.3)
trigger delay d(s) (§17.1) none (proposal; engine has none) the earliest resend after the last send: a resent seq waits the cooldown c, a never-resent seq waits min(srtt of its path, the sweep reaching it); the cartoon uses d = its RTT
one-way term ô (§17.1) none (proposal; engine has none) ô = srtt − rtprop/2, all queueing assumed on the data direction (Q18); the model has no queue, so it is RTT/2; the cartoon takes it from knob_one_way_fwd
ack timeout R (§13, RFC 6298 §2, RFC 9002 §6.2.1) none (proposal; engine has none) R = srtt + max(4·rttvar, g) + ack delay, the margin of the dequeue rule; used by the model, not set on this page
