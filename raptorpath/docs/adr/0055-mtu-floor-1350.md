# ADR-0055: MTU Floor 1350 — defeat quinn's PMTU black-hole false positive

## Status: Accepted (ships default ON)

**Date**: 2026-07-13

## Context

Wall #2: a cross-arm c3/C8 "collapse run" class (~60 s stalls at 2.2–3.3
Mbit/s, 7.6% of historic runs) was hypothesized as a receiver frontier
wedge. Forensics refuted that: quinn's PMTU black-hole detector misreads
a GE all-large loss burst as an MTU black hole — on a bulk wire
essentially every packet is a ~1279–1305 B symbol datagram, so a loss
burst "contains no packet smaller than min_mtu" by construction. quinn
then resets `current_mtu := min_mtu` (1200) < the symbol datagram size,
and EVERY data send — including every retransmit of the blocking hole —
fails sender-side with `TooLarge` for exactly `black_hole_cooldown` =
60 s. The wedge never reproduced under the L0 netem shim because the shim
drops above quinn's packet layer (the fidelity boundary, proven
load-bearing).

## Decision

Set `min_mtu = initial_mtu = 1350` — the engine's real floor (symbol
datagrams must always be sendable, so an MTU "reset" to the floor can
never make sends fail). Ships default ON; `RWM_MTU_FLOOR=0` is the stock
quinn-MTUD control arm (used by the deterministic wedge repro test).

## Consequences

- Deterministic same-binary reproduction (tests/mtu_blackhole_wedge.rs, a
  real transient MTU hole below quinn): 63.5 s → 5.8 s.
- 0/68 collapse runs in the fix arm vs 7.6% historic (p≈0.005); the
  cross-arm bimodal collapse class in the c3/C8 batteries largely
  disappears (the residual bimodality is BBR's own, ADR-0054).
- The engine assumes path MTU ≥ 1350; a genuine sub-1350 path would need
  symbol-size renegotiation, accepted as out of scope (QUIC minimum is
  1200; 1350 is chosen as the engine's measured symbol-batch floor).
- Member of the shipped default stack (ADR-0067).
