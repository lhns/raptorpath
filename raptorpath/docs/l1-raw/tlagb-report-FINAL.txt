## 3c — THE CONTROL REGRESSION CHECK. THE FOUR OLD GAUGES ARE CONTROLS
##      HERE, AND THIS SECTION IS THE ONLY THING THAT LICENSES READING
##      THE `tlag` COLUMN AT ALL.

  `tlag`'s entire claim is a COMPARISON against four predecessors
  measured in the SAME run from the SAME sample stream. If the
  predecessors do not reproduce their committed readings, this run is
  not the previous run's peer, the comparison has no referent, and a
  `tlag` number taken out of it would be a number about an unknown
  machine.

  PRE-REGISTERED CONSEQUENCE, STATED BEFORE THE NUMBERS: **IF ANY
  CONTROL MOVES BY MORE THAN 2.0x IN EITHER DIRECTION, NO VERDICT IS
  READ FROM THE `tlag` COLUMN.** Not a softened one, not a provisional
  one — none.

## 5 — CLAUSE B, REBUILT: beta vs THE GAUGE'S OWN FUNCTIONAL OVER THE
##     GAUGE'S OWN SAMPLES, FROM THE RAW [RTTDUMP] STREAM.
##     **THE REBUILT B CAN ACQUIT.**

  beta = (the gauge's ONLINE reading) / (its own functional, offline,
  over the IDENTICAL samples). Same stream, same functional, no second
  instrument, no sampling-rate gap — like-for-like BY CONSTRUCTION.
  The old B was written REJECT-only because a 20 Hz ICMP probe's
  dispersion is a LOWER bound on the ack path's. There is no such bound
  here because there is no second path, so a candidate inside the band
  is a POSITIVE finding: the online implementation reads the same
  magnitude as the functional it claims to compute. It ACQUITS.

  THE OLD `CONFOUNDED-` MARKING ON `msd` IS GONE. `msd` was confounded
  against the 20 Hz probe by a ~500x sampling-rate gap. Against its own
  stream there is no gap and nothing to confound.

  AND THE NARROWING IS RECORDED AS ONE. B now asks whether an estimator
  faithfully computes ITS functional over ITS input. It does NOT ask
  whether that input is the true delivered latency. **THE INSTRUMENT
  THE PREVIOUS BATTERY NAMED AS MISSING — a delivered-latency probe at
  the sender's own sample rate — IS STILL MISSING.** The 20 Hz probe's
  beta is printed beside every row as THE SUPERSEDED REFERENCE and NO
  VERDICT IS TAKEN FROM IT.
